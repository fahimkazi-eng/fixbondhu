# FixBondhu MVP foundation

An intentionally honest, mobile-first commercial marketplace shell for Bangladesh local services. It avoids fabricated marketplace data: there are no fake providers, ratings, job counts, reviews, or coverage claims.

## Run locally

```powershell
npm start
```

Open `http://localhost:3000`.

## What is in this build

- Customer discovery with English, Bangla, and Banglish-friendly example search flows
- Service request, location, customer sign-up, and provider onboarding interactions
- Responsive customer-facing landing experience with real-world trust and pricing language
- Explicit launch/coverage states instead of placeholder provider data

## Production implementation plan

This web shell is the customer acquisition layer; attach it to a TypeScript API and PostgreSQL application before accepting real bookings or payments.

1. **Identity and access**: password hashing, OTP-based phone verification, session rotation, explicit role claims, and server-side RBAC.
2. **Operational core**: bookings as an append-only status-transition state machine; enforce valid transitions in transactions and publish events only after commit.
3. **Verification**: document upload, manual review queue, approval/rejection history, and granular badges generated by the backend—not the browser.
4. **Money**: payment-provider adapter, signed webhook verification, immutable transaction ledger, refunds, commission calculation, and provider payout reconciliation.
5. **Communications**: booking-scoped conversations, notification outbox, background workers for SMS/email/push, and audit trails for sensitive actions.

See `docs/architecture.md` and `prisma/schema.prisma` for the implementation contract.
